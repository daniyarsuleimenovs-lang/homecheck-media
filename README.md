# homecheck-media

Картинки и видео для публикаций HomeCheck в Instagram и Threads. Metricool забирает файлы отсюда по публичной ссылке и публикует их по расписанию.

## Структура

```
posts/ГГГГ-ММ-ДД-тема/
  01.jpg, 02.jpg, …   слайды карусели, 1080×1440 (3:4)
  reel.mp4            видео для Reels, 1080×1920 (9:16)
  cover.jpg           обложка Reels
```

Ссылка на файл:
`https://raw.githubusercontent.com/daniyarsuleimenovs-lang/homecheck-media/main/<путь к файлу>`

## Важно

Репозиторий публичный: всё, что сюда попадает, доступно по ссылке ещё до публикации. Не класть сюда реальные адреса, суммы конкретных сделок и личные данные.
